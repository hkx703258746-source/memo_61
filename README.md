# memo_61
简易网页备忘录，支持新增、删除备忘记录，原生HTML+CSS+JS，无后端依赖。
> 《开源文化运动》课程作业

## ✨ 功能
1. 添加备忘
2. 删除备忘
3. 浏览器本地存储，刷新页面数据不丢失
